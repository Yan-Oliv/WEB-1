Trabalhos da disciplina **Web 1** (Sistemas de Informação).

| Pasta | Conteúdo |
|---|---|
| `Formulário HTML/` | Formulário em HTML puro, com o enunciado da atividade |
| `Trabalho Final HTML.CSS.JS/` | Site com menu, rodapé reutilizáveis e um **jogo Pac-Man** em JavaScript, com sons e fonte própria |

## Como abrir

Abra `Formulário HTML/form.html` ou o trabalho final em um navegador. O trabalho final tem um `index.php` de entrada; para usá-lo, sirva a pasta com PHP:

```bash
php -S localhost:8000 -t "Trabalho Final HTML.CSS.JS"
```
